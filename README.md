# 은퇴 5년 전 점검 가이드

똑재TV 은퇴 준비 단계형 가이드. 6단계에 숫자를 넣으면 마지막에 점검표 한 장이 나옵니다.

- 사이트: https://ttokjaetv.github.io/retire-check/
- 단일 HTML(`index.html`), 빌드 과정 없음. 더블클릭으로 열어도 동작합니다.

## 단계

1. 노후 자산 지도 — 계좌별 잔액, 국민연금 예상 월액, 재산세 과세표준, 부자지수(참고용)
2. 은퇴 시점과 생활비 — 출생연도로 국민연금 개시 나이, 소득 공백 연수
3. 소득 공백기 메우기 — 국민연금 조기·정상·연기 비교 → [은퇴 역산 계산기](https://ttokjaetv.github.io/retirement/)
4. 연금 인출 순서와 연 1,500만원 — 연금수령한도, 재원별 인출 순서 → [연금 인출 세금 시뮬레이터](https://ttokjaetv.github.io/pension-tax-sim/)
5. ISA·일반계좌 정리 — 만기 자금 연금 이전 추가 세액공제, 금융소득 경계선 → [ISA 만기 전략 계산기](https://ttokjaetv.github.io/isa-maturity/)
6. 건보료 피부양자 점검 — 부부 단위 소득·재산 판정

## 제도 기준 (2026-10 확인)

| 항목 | 기준 |
| --- | --- |
| 사적연금 연금소득세 | 55~69세 5.5%, 70~79세 4.4%, 80세 이상 3.3% |
| 사적연금 분리과세 | 연 1,500만원 이하 저율 분리과세, 초과 시 전액 종합과세 또는 16.5% 분리과세 |
| 연금수령한도 | 평가액 ÷ (11 − 연금수령연차) × 120% |
| 퇴직금 연금수령 감면 | 퇴직소득세 30%(10년차까지), 40%(11~20년차), 50%(20년 초과) |
| 국민연금 | 1969년생 이후 65세 개시, 조기 1년당 6%, 연기 1년당 7.2% (각 최대 5년) |
| ISA 만기 연금 이전 | 만기 후 60일 이내, 이전액의 10% 최대 300만원 추가 세액공제 |
| 피부양자 소득 | 합산 연 2,000만원 이하 (공적연금 전액, 금융소득 1,000만원 초과 시 전액, 사적연금 제외) |
| 피부양자 재산 | 과표 5.4억원 초과~9억원 이하면 소득 1,000만원 이하, 9억원 초과면 제외 |
| 부자지수 (참고용) | 순자산 × 10 ÷ (나이 × 세전 연소득), 『이웃집 백만장자』(토마스 스탠리) — 200% 이상 우수, 100% 기준, 50% 미만 부진 |
| 생활비 기본값 | 국민연금연구원 2024년 국민노후보장패널 제10차 부가조사 |

매년 1월·7월에 개정 여부를 다시 확인합니다.

## 저장

입력값은 방문자 브라우저의 localStorage(`retireCheck.v1`)에만 저장됩니다. 서버로 보내지 않습니다.
